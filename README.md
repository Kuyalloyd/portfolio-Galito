# 🚀 Modern React Portfolio

A beautiful, animated, and fully responsive portfolio website built with React, Tailwind CSS, and Framer Motion.

## ✨ Features

- **Smooth Animations**: Built with Framer Motion for professional, smooth transitions and interactions
- **Responsive Design**: Fully responsive and mobile-friendly using Tailwind CSS
- **Modern UI**: Clean, modern design with gradient backgrounds and glass-morphism effects
- **Interactive Components**: Engaging hover effects and interactive elements
- **Fast Performance**: Optimized with Vite for lightning-fast load times
- **Easy Customization**: Simple to customize colors, content, and styles

## 🎨 Sections Included

1. **Navigation Bar** - Fixed, animated navbar with mobile menu
2. **Hero Section** - Eye-catching introduction with CTA buttons and social links
3. **About Section** - Biography, experience timeline, and decorative elements
4. **Projects Section** - Showcase of featured projects with tags and links
5. **Skills Section** - Technical skills with proficiency levels
6. **Contact Section** - Contact form and contact information
7. **Footer** - Social links and quick navigation

## 🛠️ Tech Stack

- **React** - UI library
- **Vite** - Next-generation build tool
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **React Icons** - Icon library

## 📦 Installation

1. Navigate to the project directory
2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## 🔨 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview the production build locally

## 🎨 Customization

### Colors
Edit the color scheme in `tailwind.config.js`:
```javascript
colors: {
  primary: "#6366f1",      // Change primary color
  secondary: "#ec4899",    // Change secondary color
  dark: "#0f172a",
  darker: "#020617",
}
```

### Content
Update the portfolio content in the respective component files:
- Hero section - `src/components/Hero.jsx`
- About section - `src/components/About.jsx`
- Projects - `src/components/Projects.jsx`
- Skills - `src/components/Skills.jsx`
- Contact - `src/components/Contact.jsx`

### Animations
Modify animation timing and effects in the component files using Framer Motion variants.

## 📝 Configuration Files

- `vite.config.js` - Vite configuration
- `tailwind.config.js` - Tailwind CSS configuration
- `postcss.config.js` - PostCSS configuration
- `package.json` - Project dependencies and scripts

## 🚀 Deployment

### Deploy to Vercel (Recommended)
```bash

vercel
```

### Deploy to Netlify
```bash
npm run build
# Drag and drop the 'dist' folder to Netlify
```
